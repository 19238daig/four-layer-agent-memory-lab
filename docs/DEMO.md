# 前端演示手册

双击“打开记忆演示.cmd”启动，或在服务已运行时打开 **http://127.0.0.1:8010/**。之后所有演示操作都在页面完成。

## 操作方式

默认进入“交互演示 → 分步演示”。每一步都可以编辑日常示例，再点击右下角的执行按钮。模型运行时显示正在执行的操作，结果自动同步，不需要复制命令。

下方有三个结果页签：

- **输出结果**：显示本步产生的消息、笔记、主题页、上下文或回答。
- **输入与输出**：展开真实处理步骤，检查对应输入和输出。
- **引用来源**：点击来源 ID，继续查看原文摘录、历史版本和上下文。

完成一步后点击“下一步”。也可以直接选择左侧步骤，缺少前置数据时页面会提示。刷新后保留已完成结果、步骤位置与编辑的输入。

## 1. 录入日常偏好

保留示例或自行修改，一行一条：

> 我平时不吃辣，午饭最好控制在80块以内。
>
> 给我建议的时候，简单列两三条就好。

点击 **保存日常消息**。原始记录增加，其他层不变；本步不调用模型。

## 2. 提取记忆笔记

点击 **提取记忆笔记**。一般生成不吃辣、午饭预算、回复风格三条笔记，标题由模型生成。

切换到“引用来源”，点击 T 开头的来源，检查逐字原文。重复提取同一批已处理消息不会再次调用模型。

## 3. 整理主题与索引

点击 **整理主题与索引**。生成带笔记引用的主题 Wiki，并更新精简启动记忆。完整的饮食事实留在主题层；少量通用风格和主题目录进入 L4。

点击某个输出可查看引用笔记、交叉链接、版本和被替代版本。

## 4. 预览注入上下文

点击 **预览注入上下文**。预览明确标记未发送，不调用模型。查看启动偏好与目录，注意索引不等于事实正文。

## 5. 换个会话问午饭

可以直接使用：**周末午饭吃点什么比较合适？**

点击 **提问并观察记忆**。每次执行本步都创建新会话，避免携带上次的聊天历史。查看回答是否使用不吃辣、80元预算和简短风格，并点击引用来源。

“查看实际上下文”可以检查固定指令、启动记忆、当前会话、检索材料与当前问题的分区。

已读取、已进入上下文、回答明确引用，是不同的可观察状态，不等同于模型内部推理证明。

## 6. 改一下午饭预算

示例修改：**以后午饭预算改成120块吧，还是不吃辣。**

验证问题：**明天中午帮我想两种吃法。**

点击 **更新预算并验证**，页面依次执行四个真实操作：保存 → 提取 → 整理 → 新会话提问。观察新预算生效，同时旧笔记与旧回答来源仍然保留。

## 7. 从原话找回猫名

示例原话：**对了，我家猫叫年糕。**

问题：**我家猫叫什么来着？**

点击 **保存原话并提问**。本步故意不生成笔记或主题；回答应从原始记录找到猫名，引用 T 开头的消息。

## 8. 问一个无关问题

示例：**为什么天空看起来是蓝色的？**

点击 **提问并检查筛选**。查看实际读取材料，预期不检索饮食和猫名。L4 少量通用信息与索引仍存在。

## 9. 和 Deep Agents 比较

点击 **开始真实方案对比**。通常需要几分钟，取决于消息数量与服务速度。

三组使用相同显式录入消息、模型和当前问题，在独立空间运行：

- 无记忆：仅接收当前问题。
- 四层记忆：重新提取、整理，再用新会话回答。
- Deep Agents：真实 agent 更新 AGENTS.md，再用新 thread 回答。

三组回答与实际 token/调用数直接显示在本步结果中。“完整详情”可查看模型与工具轨迹。统计包含学习与回答，计算过程不同，不能当作框架性能排名。

## 自由操作

切换到“自由操作”，选择操作类型、会话名称和日常消息，点击 **执行操作**。你可以自由组合录入、提取、整理、预览、提问和对比。

相同会话名称继续聊天；更换会话名称演示跨会话记忆。“新建空白演示”创建新的独立空间，已有内容不删除。

## 历史与回放

从左侧“最近运行”打开详情，点击“回放”，即可查看已有真实轨迹，不会发起新的模型调用。

## 常见问题

- 页面仍是旧版：刷新页面；必要时按 Ctrl+F5 强制刷新。
- 服务未连接：双击工作区根目录“打开记忆演示.cmd”或“start-demo.cmd”。
- 提取没有新笔记：材料可能已处理，或不适合长期保留，查看跳过原因。
- 只有笔记更新，主题没变：继续执行整理主题，更新 Wiki 与启动索引。
- 模型执行失败：页面保留错误与已完成步骤，可从运行详情检查后重试。
- 不想混入已有偏好：点击“新建空白演示”，从第1步开始。
